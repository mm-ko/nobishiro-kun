# 子どもの学習トラッキング

## Issue

* **誰の課題？：**
  共働きで多忙な30代夫婦(小学3年生の子を持つ親)

* **なにに困っている？：**
  子どものテストの間違いを解き直しさせて終わってしまい、どの単元を繰り返し間違えているのか、次に何を優先して勉強させればよいか分からない。
  分析する時間もなければ、それに使える良いツールも見つけられていない。子供に良質な教育環境を与えたいと思っているからこそ、「今のままでいいのか」というモヤモヤを抱えている。

* **本来はどうあるべき？：**
  テストやプリントの間違いが自動的に蓄積・分析され、苦手分野やつまずきのパターンが親子ともに可視化される状態。
  親が忙しくても、次にやるべき学習の優先順位が一目でわかる。

* **既存のソリューションは？：**
  以下のような類似サービスが存在するが、いずれも保護者が家庭で完結して使える形での「実テスト読取+分析」を提供するものではない。

  | サービス | 対象 | 特徴 | 備考 |
  |---|---|---|---|
  | atama+ / Qubena / すらら | 学校・塾 | 独自カリキュラムで子どもが解答 | 学校の実テストには非対応 |
  | Marubatsu AI / testus | 学校・塾 | テスト作成・採点支援 | 教員向けツール |
  | LetEval | 学校+保護者閲覧 | 教師がアプリ内で試験作成→保護者が結果閲覧 | アプリ内試験が前提 |
  | 宿題サポート『採点くん』 | 保護者 | 宿題を撮影→AIが自動採点→苦手分析 | AIが独自採点(学校の採点は使わない) |
  | アンカー(Study Valley) | 保護者 | 実テスト撮影→AI苦手分析 | 2026年9月時点で終了の可能性 |
  | お受験マネージャー | 中学受験家庭 | 撮影登録→苦手可視化→忘却曲線で復習提案 | 受験特化 |
  | マジタク | 小学校受験家庭 | 苦手分析→問題自動印刷、前向き声かけ | 受験特化(伸芽会と実証実験) |

  それ以外は、親がノートに記録する、記憶に頼る、特に何もしないといった手動対応にとどまっている。

* **その課題が解決されたらいくら払う？：**
  未検討(次回チームで議論予定)


## Solution

#### 理想状態
テストやプリントの間違いが自動的に蓄積・分析され、苦手分野やつまずきのパターンが親子ともに可視化される状態。親が忙しくても、次にやるべき学習の優先順位が一目でわかる。

* **どうやって解決する？：**
  親がテストやプリントの結果を記録していくことで、間違いの傾向が自動的に蓄積され、苦手分野やつまずきのパターンが見える形になる状態を目指す。記録された内容をもとに、単元別の苦手傾向を前向きな言葉(例：伸びしろ、あと少し)とともに示し、「まずはここから」といった次に取り組むべきことのヒントを提示する。記録が積み重なるにつれて、繰り返しつまずいている単元の傾向を捉えたり、より具体的な学習のヒントを示したりすることも見据える。

  次のステップにつなげる際は、理想的には該当単元の問題やプリントへのつながりを示したり、「今週はこの単元を少しだけやってみよう」といった小さな目標を示したりすることも視野に入れる。まずは傾向を示すところから始め、段階的にできることを広げていく。演習問題や市販ドリルの提案のような大きな機能は拡張の段階として見据えつつ、まずは、教科書のここの部分をもう一度読んでみると、理解が深まるかもしれない、というような、次につながる軽い一言を添えることを考えている。教科書は出版社によって単元の並び方やページ構成が異なるため、ページ数などの具体的な指定はせず、まずは単元名レベルでの声かけに留める。可視化して終わりではなく、次の一歩をそっと後押しする存在でありたい。

  また、しばらく記録が滞ってしまっても責めるのではなく、「今週返ってきたテストやプリントはありますか？まとめて整理しますよ」、月初や長期休み前には「読み込み忘れはありませんか？」といった、柔らかいトーンの声かけを行う。

* **実現できたら実際に解決できる？：**
  本当の意味での課題解決を「子どもの行動が変わること」と定義するなら、傾向を示すだけでは十分に解決しきれない。ただし、本企画では課題を段階的に捉える。

  **第一段階(まず解決したい課題)**：「忙しくても子どもに関わりたい」という親の気持ちを、傾向の可視化を通じて満たすこと。苦手が見える化されること自体が、「子どもに関われている」という親の自己肯定感につながり、「今のままでいいのか」というモヤモヤを和らげる。加えて、見える化された内容は、学校の個人面談で先生に相談する際の具体的なきっかけとしても活用でき、家庭内で完結する価値にとどまらない。

  **第二段階(将来的に見据える課題)**：子ども自身の行動が変わること。間違いの内容やレベルに合わせたおすすめの取り組み方の提示など、より能動的な後押しが必要になる。これは開発の進み具合に応じて段階的に広げていく。

* **優位性は？：**
  同様のアイデア自体はアンカー・採点くん・お受験マネージャー・マジタクなど複数の先行事例があり、目新しいものではない。特にアンカーは学校のテストを撮って苦手を分析するという、本企画とほぼ同じ発想をすでに形にしていた。それでもなお、こうした試みが次々と生まれ、一部は姿を消しながらも別の形で再挑戦され続けているという事実は、裏を返せば「解決したいと思う人が繰り返し現れるほど根の深い課題」であることの証左でもある。だからこそ、単に「新しいアイデアかどうか」ではなく、「なぜ自分たちの立ち位置なら続けられるのか」を語ることが重要になる。

  | 比較軸 | 主な競合 | 本サービス |
  |---|---|---|
  | 対象 | お受験マネージャー(中学受験)／マジタク(小学校受験) | 受験不問、日常学習で困っている家庭 |
  | 採点の考え方 | 採点くん(独自に正誤を判定する) | 先生がすでに採点した結果をそのまま活用する |
  | コンテンツ制作 | アンカー(独自の授業動画・問題を自社制作、恐らく終了) | 独自教材は作らず身軽な運営 |
  | 心理的アプローチ | マジタク(子どものやる気を引き出す) | 親の罪悪感・モヤモヤを軽減する |

* **デメリットや副作用はある？：**
  記録の正確さには限界があり、誤って記録された場合、誤ったデータに基づいて苦手分野を示してしまうリスクがある。曖昧な部分は親が確認・修正できるようにすることでリスクを軽減するが、確認の手間が大きい場合は継続利用が難しくなる可能性もある。

  また、苦手の可視化は親の安心につながる一方で、可視化されることで親が子どもの学習に必要以上に干渉するようになったり、子ども自身が「間違いを継続的に評価される」というプレッシャーを感じたりする可能性もある。前向きな言葉を添えるなどの配慮を設計に取り入れているが、根本的な解決策ではなく、運用上の注意が必要な副作用として認識しておく必要がある。

  加えて、学校のテスト・プリントには著作権があり、記録の残し方によっては配慮が必要になる。また、当面は一部の教科に絞る想定のため、他教科を望む家庭には価値が限定的であり、親が記録を継続しなければ傾向も蓄積されず、示せるヒントの精度も上がりにくいという運用上の課題もある。

* **デメリットと天秤にかけてもこのソリューションを使うべき？：**
  Yes。
  撮影・確認という新たな手間が生じるため、物理的に親の負担が完全になくなるわけではない。しかし、そもそも「忙しくても子どもに関わりたい」と願う親をペルソナとしている以上、その気持ちを空回りさせず、意味のある行動へと昇華させられる点に価値がある。

  また、昨今の物価高や送迎の負担から本格的な塾通いをためらう家庭も少なくなく、家庭内で完結できる本サービスは、そうした層のニーズにも応えられる可能性がある。加えて、可視化されたデータは学校の個人面談で先生に相談する際の具体的なきっかけにもなり、すでにある学校という相談先をより有効に活用する助けにもなる。

  ただし、デメリットで挙げた心理的な副作用を踏まえ、子どもが画面を覗いた際に恐怖や悲しみを感じないよう、UI・言葉選びに十分な配慮を行うことを前提とする。

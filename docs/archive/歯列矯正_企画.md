# 歯列矯正 × 食事サポート

## Issue

* **誰の課題？：**
  歯列矯正中で、歯の痛みによって食べられるものが制限されている20代女性

* **なにに困っている？：**
  歯の痛みがある日は硬いものや噛み切りにくいものを避ける必要があり、「今の状態でも食べられるもの」を毎回自分で探さなければならない。
  また、柔らかさを優先すると食事が偏りやすく、栄養面への不安があるほか、食べたいものを我慢することで食事を十分に楽しめない。

* **本来はどうあるべき？：**
  その日の歯の状態に合わせて、無理なく食べられる料理を簡単に見つけられ、栄養バランスを保ちながら「食べられるもの」だけでなく「食べたいもの」を選べる。
  歯列矯正中でも、健康と食事の楽しみを両立できる状態。

* **既存のソリューションは？：**
  Googleなどの検索エンジン、SNS、レシピサイトなどで「矯正中 食事」「歯が痛い 柔らかい レシピ」などと検索し、その日の状態に合いそうな料理を自分で探す。
  ただし、「歯への負担」「栄養」「食べたいもの」など複数の条件を踏まえて探すには、複数の情報を自分で比較・判断する必要がある。

* **その課題が解決されたらいくら払う？：**
  **300〜500円 / 月**
  日常的に利用する食事サポートサービスとして、気軽に継続できる価格帯を想定。


## Solution

#### 理想状態
歯列矯正中でも、“食べられるもの”だけから選ぶのではなく、その日の自分に合った方法で“食べたいもの”を楽しめる状態。

* **どうやって解決する？：**
  ユーザーが現在の歯の痛みと「今食べたいもの」を入力すると、その日の状態に合わせて食事の選択肢を提案する。

  Web上に適したレシピや商品、外食メニューがある場合は検索して具体的な候補を提示する。一方で、「歯が痛いけれどエビチリが食べたい」など、検索だけでは条件に合う情報が見つからない場合には、AIが料理の食材や食感などを考慮し、より食べやすい食材への置き換えや調理方法を提案する。レシピや商品名の詳細は出典元のWebサイトで確認できるようにする。

  また、提案された食事を実際に食べたあとに「痛かった / 痛くなかった」を評価できるようにする。検索や提案を利用せずに食べたものについても、自分で食事内容と痛みを記録できるようにし、アプリ内外を問わず日々の食事結果を蓄積する。

  一つの食事に複数の料理や食材が含まれる場合には、「寿司は痛かった」と一括りにするのではなく、「マグロは痛くなかったが、イカは痛かった」のように、それぞれの食材について評価できるようにする。

  これらの食事履歴を次回以降の提案に反映することで、単に「この料理が食べられるか」だけでなく、「弾力のある食材では痛みが出やすい」など、ユーザーごとの食材や食感に対する傾向を把握し、使うほどその人に合った食事を提案できるようにする。

  自炊だけでなく、コンビニの商品や外食メニューも対象とし、「作る・買う・外食する」のさまざまな場面で、そのときの自分に合った食事を探せるサービスを目指す。

  発展的な機能として、蓄積された食事履歴から栄養バランスの偏りを可視化し、「食べやすさ」だけでなく栄養面も考慮した食事選びをサポートする。

* **実現できたら実際に解決できる？：**
  Yes。痛みの程度だけでなく過去の食事結果を提案に反映することで、ユーザーが「今の自分でも食べられそうか」を毎回一から調べて判断する負担を減らせる。

  また、自炊用のレシピだけでなく、コンビニ商品や外食メニューまで選択肢に含めることで、仕事中・帰宅途中・友人との外食など、さまざまな生活場面で利用できる。

  さらに、「食べたいもの」がそのままでは食べにくい場合にも、AIが代替食材や調理方法を提案することで、「食べられるもの」だけから選ぶのではなく、「食べたいものを、食べられる形にする」という選択肢を提供できる。

* **優位性は？：**
  一般的なレシピサイトや検索サービスが「料理を探す」ことを目的としているのに対し、本サービスは「今の自分の歯の状態で食べられるものを探す」ことに特化している。

  自炊用のレシピだけでなく、コンビニで購入できる商品や外食チェーンの実際のメニューまで横断して検索することで、「作る・買う・外食する」といったさまざまな食事シーンで利用できる。

  さらに、現在の痛みだけでなく、過去に食べたものに対する「痛かった / 痛くなかった」という評価を蓄積し、次回以降の提案に活用することで、使うほど自分に合った食事を見つけやすくなる。

  検索しても条件に合う情報が見つからない場合には、AIが食材や調理方法の代替案を提示し、「食べたいものを諦めないための提案」ができる点も特徴とする。

* **デメリットや副作用はある？：**
  痛みの感じ方には個人差があるため、アプリが提案した食事でも痛みを感じる可能性がある。また、コンビニ商品の販売状況や商品情報は変更されるため、提案した商品が実際には販売されていない可能性がある。

  栄養や歯の状態について医療的な判断を行うサービスではないため、ユーザーが提案内容を「医学的に安全である」と誤認しないための配慮も必要となる。

* **デメリットと天秤にかけてもこのソリューションを使うべき？：**
  Yes。食べられることや医学的な安全性を保証するのではなく、「現在の状態で食べられそうな候補を探すためのサポート」として利用することで、リスクを抑えながら、毎日の食事選びや検索・比較にかかる負担を減らせる。

  また、単に柔らかい食事を探すだけでなく、「食べたいものをどうすれば食べられるか」という選択肢を提供することで、歯列矯正中でも食事の楽しみを維持することにつながる。
